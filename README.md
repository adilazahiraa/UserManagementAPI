# UserManagementAPI

ASP.NET Core Web API project developed for learning CRUD operations, middleware, serialization, deserialization, and Swagger/OpenAPI integration.

## Features

- CRUD API endpoints
- Middleware logging
- API key authentication
- Error handling middleware
- Swagger / OpenAPI documentation
- JSON and XML serialization
- Secure deserialization validation

## Technologies Used

- ASP.NET Core
- C#
- Swagger / OpenAPI
- Serilog
- GitHub

## API Endpoints

### User/Product Endpoints
- GET
- POST
- PUT
- DELETE

### Serialization Endpoints
- /manual-json
- /json
- /xml
- /save-person-files
- /read-person-files

### Security Endpoints
- /secure-serialize-user
- /secure-deserialize-user

## Notes

This project includes middleware implementation, request logging, validation, and API documentation using Swagger.
